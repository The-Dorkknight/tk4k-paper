# TK 4K paper

> **Alpha / work in progress.** The paper that goes with [TK 4K](https://github.com/The-Dorkknight/tk4k) 0.5.6, a small modern Tk-shaped Python GUI toolkit on SDL3 + Dear ImGui. Part defensive publication, part easy-to-read paper.

**[Open or download the PDF: TK4K-paper.pdf](TK4K-paper.pdf)** (24 pages, A4, about 1.4 MB). GitHub also shows it in its own viewer when you click the file. The pages are repeated below so you can read it right here.

Author: Matthew Armstrong (The-Dorkknight), written with Claude. Licence: Apache-2.0, like TK 4K itself (see [LICENSE](LICENSE)).
